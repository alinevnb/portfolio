# 🍂 Portfólio Aline Vitória Nunes Barros

Portfólio moderno, acolhedor e limpo desenvolvido para **Aline Vitória Nunes Barros**, estudante de Informática para Internet no **IFAC (Instituto Federal do Acre)** e microempreendedora no campus.

---

## 🎨 Identidade & Conceito Visual
- **Tema:** Outono contemporâneo (*Autumn Warmth & Clean Minimalist*)
- **Paleta de Cores:** Tons de laranja outonal, terracota, caramelo e marrom aveludado sobre fundo marfim/creme suave.
- **Micro-interações:** Folhas de outono flutuando suavemente em segundo plano (com controle interativo para pausar/ativar), animações hover fluidas, confetes comemorativos e visualizador de comprovantes.

---

## 🌟 Seções do Portfólio

1. **Header & Navegação:** Menu responsivo com efeito glassmorphism e atalho para encomendas.
2. **Hero:** Apresentação marcante com foto de perfil expressiva, crachás do IFAC e botões de ação rápida.
3. **Sobre Mim:** Narrativa sincera e motivadora, destacando determinação, dedicação, perfil autodidata e versatilidade prática.
4. **Alfajores da Aline (Microempreendedorismo):** Vitrine especial dos doces artesanais vendidos no campus, foto real, seleção de sabores, depoimentos e link direto para pedidos via Instagram.
5. **O Que Eu Domino:** Apresentação moderna das competências práticas em Excel Avançado, PowerPoint Profissional, Segurança da Informação e Formação Técnica no IFAC.
6. **Habilidades em Ação:** Barras dinâmicas de competências divididas em Ferramentas/Office, Negócios/Vendas e Informática/Competências Interpessoais.
7. **Contato:** Formulário de envio de mensagens e links diretos para Instagram e localização no campus IFAC.
8. **Rodapé:** Créditos elegantes e botão de retorno ao topo.

---

## 🛠️ Tecnologias Utilizadas
- **React 18**
- **Vite 6**
- **Tailwind CSS 3**
- **Lucide React** (Ícones modernos)
- **Canvas Confetti** (Micro-interações festivas)

---

## 🚀 Como Executar o Projeto

### Pré-requisitos
- Node.js instalado (v18+)
- npm ou yarn

### Instalação
```bash
npm install
```

### Modo de Desenvolvimento
```bash
npm run dev
```
Acesse `http://localhost:3000` no seu navegador.

### Build de Produção
```bash
npm run build
```
Os arquivos otimizados para deploy serão gerados na pasta `dist/`.
